# Приёмка: запасной вид без 3D и счётчики сбоев

[Бриф](../specs/no-webgl.md). 2026-10-14, ветка `claude/no-webgl`.

## До правки (живой сайт)

Edge с `--disable-webgl --disable-3d-apis`: `THREE.WebGLRenderer: Error creating WebGL context`, React снимает
дерево — пустая страница, текста 0 символов. Обычный Edge на телефоне: стартовый экран 0,7–1,7 с, на медленном 3G
(1,6 Мбит/с, 150 мс) — 3,8 с; три недели без ошибок.

## После правки

Production-сборка (`vite preview`, GoatCounter подменён заглушкой, события копятся в `window.__gc`), Edge, Playwright.
Сценарий: стартовый экран → «Начать игру» → три недели.

| Сценарий | Итог |
|---|---|
| 3D, телефон 390×844 | холст есть, картинки нет, события `game-start`, `profession-teacher` |
| 3D, ноутбук 1366×768 + 5 брошенных ошибок | холст есть; ровно 3 события `js-error`, повтор `probe-A` схлопнут |
| Без WebGL, телефон | `island-still-tall.jpg` на весь экран, тост «В этом браузере нет 3D…», событие `no-webgl` |
| Без WebGL, ноутбук, `/en/` | `island-still-wide.jpg`, английский тост, `no-webgl` |
| Проба WebGL проходит, контекст three.js — нет | граница ошибок: картинка, тост, `scene-error «THREE.WebGLRenderer: Error creating WebGL context.»` |

Во всех пяти: HUD на месте, горизонтальной прокрутки нет, ошибок страницы нет (кроме намеренных проб).
`npm run typecheck` и `npm run build` проходят; движок не менялся.

Известное: картинка не сдвигается вслед за шторкой на телефоне — при открытой шторке дом частично под карточками
показателей. Для запасного вида допустимо. Потеря контекста WebGL во время игры (без исключения) не ловится.

Скрипт проверки — `check-no-webgl.mjs` (в рабочей папке координатора; сценарии перечислены выше).
