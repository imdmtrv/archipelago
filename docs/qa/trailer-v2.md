# Приёмка: пересъёмка роликов (v2)

2026-10-15, ветка `claude/trailer-v2`, рендер на машине владельца (NVIDIA RTX 3060, Edge, Playwright).

## Зачем

Ролики в пре-релизе `trailer-chat` показывали старый дом, а в последнем кадре — адрес `dmtrml.github.io`, который
после переноса репозитория отвечает 404. Версий с новым адресом на машине не нашлось.

## Что мешало и что исправлено

- **Окно свободы открывалось прокрученным вниз.** У кнопки «Остаться на работе» был `autoFocus`; кнопка внизу
  высокого окна (после «Поделиться» v3 в нём есть карточка вызова), браузер прокручивал окно к ней на 498 px, и
  заголовок «Финансовая свобода!» уходил за верх экрана. Это ошибка игры на телефонах 360×640, не только ролика:
  рендер остановился на встроенной проверке `freedom: modal title not fully visible`. Исправлено общим
  `focusOnMount` (`ui/common.tsx`, `focus({ preventScroll: true })`) — фокус для клавиатуры остаётся, прокрутки
  нет. То же у кнопок «Дальше» в итогах недели и в эпилоге.
- **Первая подпись** «600 монет и маленький остров» устарела после профессий (старт у всех разный) →
  «Маленький остров и работа» / «A tiny island and a job» (`director/shots.ts`), как в окне приветствия.
- Запуск только через `npm run trailer -- …`: прямой `node scripts/trailer/render.mjs` на Node 22 падает
  на `spawnSync npm.cmd EINVAL`.
