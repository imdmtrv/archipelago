# Приёмка: правки по первой игре владельца на телефоне

[Бриф](../specs/mobile-fixes-1.md). 2026-10-15, ветка `claude/mobile-fixes`. Код — Codex (`gpt-6.1-sol`),
одна правка свайпа и проверка — Claude.

Playwright, Edge, 390×844 с касаниями (`isMobile`, `hasTouch`), `--autoplay-policy=user-gesture-required`;
свайпы — CDP `Input.dispatchTouchEvent`. Одна и та же проверка до правки (живой сайт) и после (production-сборка).

| Проверка | До | После |
|---|---|---|
| Пузырь обучения скрыт, пока открыто окно итогов недели | ✗ (шаг 2 поверх окна) | ✓ |
| Шаг 3 сразу после закрытия окна | ✓ | ✓ |
| Карточка соседа целиком в экране | ✗ (195…553 при ширине 390) | ✓ (12…378) |
| Свайп вверх открывает шторку / вниз закрывает | ✗ (свайпа нет) | ✓ / ✓ |
| Касание ручки переключает шторку | ✓ | ✓ |
| Цели свёрнуты в строку ≤ 56 px | ✗ (блок 411 px) | ✓ (48 px), касание раскрывает |
| Отчёт недели от начала вкладки «Отчёт» | 748 px | 185 px |
| Компьютер: вкладка «Цели», без шторки и прокрутки вбок | ✓ | ✓ |
| Ошибки страницы | нет | нет |

Порядок вкладки «Отчёт» на телефоне: прогресс свободы → цели (свёрнуты) → отчёт недели → мечта; после свободы
мечта поднимается под прогресс.

**Найдено при приёмке и исправлено:** свайп не срабатывал на сенсорном экране — `lostpointercapture` всплывал от
ручки, когда касание переходило к шапке шторки, и принимался за отмену жеста (`ui/Panels.tsx`).

**Звук.** Разблокировка теперь на `pointerdown`, `pointerup`, `touchend`, `click`, `keydown`; повторный `resume()` при
каждом жесте. Chromium запускает звук и без правки, поэтому подтверждение — только на телефоне владельца.
На iPhone звук сайтов не играет в беззвучном режиме (переключатель сбоку) — это поведение Safari.
