# Этап 2 «Своя история»: профессии и сокращение

Ветка `claude/professions`. [Дорожная карта, этап 2](../ROADMAP.md#этап-2-своя-история): каждая партия начинается
по-своему. Выбор мечты — позже (нужны новые 3D-модели). Общие правила — как в
[engagement-1](engagement-1.md#общие-правила).

**Урок профессий:** к свободе ведёт не размер зарплаты, а разница между доходом и расходами — финиш свободы равен
расходам. **Урок сокращения:** от потери работы защищают подушка и пассивный доход.

## Контракт (уже в коде — координатор)

- `types.ts`: `ProfessionId` (`keeper` | `teacher` | `captain` | `doctor`), `ProfessionDef { salary, living, cash, loan }`;
  поля игрока `profession`, `layoffWeeks`, `lastLayoffWeek`; мир `version: 7`.
- `content.ts`: `PROFESSIONS` (стартовые числа для подбора), `PROFESSION_ORDER`. `createWorld` принимает `profession?`.
- `rules.ts`: `LAYOFF_WEEKS`, `LAYOFF_COOLDOWN`.
- Словари RU: `professions.*`, `events.layoff` (`reason[профессия]`, `text(reason, weeks)`), `events.layoffOver`,
  `news.layoff(name)`, `ui.report.layoff(weeks)`, `ui.welcome.profession*`. В `en.ts` — `TODO`.

## 1. Движок — Codex 1

**Файлы:** `packages/engine/**`.

- **Профессии.** `createWorld({ profession })` (по умолчанию `teacher`): у человека зарплата, расходы, наличные — из
  профессии; `loan > 0` — обычный кредит через `addLoan` (у врача — «за учёбу»; цель `debtFree` от этого сразу доступна).
  Стартовая доска гарантирует актив по карману — по наличным человека, а не `START_CASH`. Боты: Мия — `keeper`,
  Тимур — `captain`, Борис — `teacher`.
- **Сокращение** — личное событие `layoff` с весом 0.06 в `PERSONAL_EVENT_WEIGHTS`. Бывает только на работе, без текущего
  сокращения и не раньше `LAYOFF_COOLDOWN` недель после прошлого (иначе — нет события, как у `raise` без работы).
  `layoffWeeks = int(LAYOFF_WEEKS)`, `lastLayoffWeek = неделя`; событие `layoff` (bad, `params: { weeks, profession }`).
  Со следующей недели и пока `layoffWeeks > 0`: зарплата 0, подработки нет (`setExtraShift on` → ошибка `shiftUnemployed`),
  выгорания нет; в конце каждой такой недели `layoffWeeks − 1`, на нуле — событие `layoffOver` (good).
  Уход с работы после свободы обнуляет сокращение. `financeView.salary` во время сокращения — 0.
  Ботов тоже сокращают; новость `{ kind: 'layoff' }` о соседе.
- **Миграция** v6 → v7 (и старше): человек — `teacher`, боты — по ростеру выше, `layoffWeeks: 0`, `lastLayoffWeek: 0`;
  их зарплату и расходы не трогать.
- **Симулятор.** Разумный игрок за каждую из четырёх профессий (500 сидов × 100 недель) и новые цели:
  - каждая профессия: свобода к 100-й неделе в ≥ 95% игр, медиана 25–48 недель;
  - разброс медиан профессий (макс − мин) ≤ 12 недель — заведомо проигрышных нет;
  - никто не лучший во всём: профессия с самой ранней медианой свободы — не та, у которой самый большой медианный
    капитал на 100-й неделе;
  - печатать среднее число сокращений за игру. Все прежние цели — `OK` (второй акт и улучшения — у учителя, как раньше).
- **Что можно подбирать** (и только это): числа `PROFESSIONS` в пределах ±40 к зарплате и расходам, ±200 к наличным,
  кредит врача 0–2000; `LAYOFF_WEEKS` в пределах 2–8; вес `layoff` 0.03–0.1. **Другие числа правил не менять.**
  Если цели не держатся в этих пределах — остановиться и сообщить числа.
- **Тесты:** старт каждой профессии (деньги, зарплата, расходы, кредит врача), боты, сокращение (условия, зарплата 0,
  подработка запрещена, `layoffOver`, перерыв), миграция v6 → v7.
- Проверка: `npm run -s typecheck`, `npm test -- --reporter=dot`, `npm run -s sim`.

## Баланс, вторая итерация (координатор)

Первая подборка прошла все цели, но капитан (26 недель, капитал 52 тыс.) и врач (27, 59 тыс.) оказались лучше учителя
(37, 33 тыс.) и по скорости, и по капиталу — учитель стал заведомо проигрышным, а урок перевернулся. Сокращение ослабло
до 2 недель с весом 0.03 — урока нет. Новые условия (вместо раздела «Что можно подбирать»):

- **Учитель неизменен:** 180 / 150 / 600 / 0.
- **Пределы:** смотритель — зарплата 110–150, расходы 80–110, наличные 300–600; капитан — 240–300, 200–260, 600–1000;
  врач — 320–420, 250–320, 300–700, кредит 1000–2000. Сокращение: `LAYOFF_WEEKS` внутри 3–6, вес 0.05–0.08.
- **Новые цели симулятора** (к прежним):
  - Парето: ни одна профессия не лучше другой одновременно по медиане свободы (раньше) и по медианному капиталу на
    100-й неделе (больше); равенство — не «лучше»;
  - смотритель маяка — самая ранняя медиана свободы (урок: низкие расходы — близкий финиш);
  - остальные: свобода в ≥ 95% игр, медиана 25–48, разброс медиан ≤ 12.
- Других чисел правил не менять. Не держится — остановиться и сообщить таблицу.
