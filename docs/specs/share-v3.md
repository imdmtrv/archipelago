# «Поделиться», третья итерация: короткая ссылка, ссылка-слово, личная карточка на «ты»

Ветка `claude/professions` (PR #18). Отзыв владельца после отправки в Telegram: ссылка огромная; на карточке «Вы: …»
(имя по умолчанию); хочется «Дима обрёл финансовую свободу за 12 недель», «Сможешь быстрее?» и потом остальное.
Общие правила — как в [engagement-1](engagement-1.md#общие-правила). Файлы: `apps/web/src/**` (кроме `director/**`),
`scripts/check-first-minutes.mjs`. RU — дословно из таблицы, EN — `'TODO'`. Движок не трогать.

## 1. Короткий код вызова (`challenge.ts`)

- Новый формат `v: 2` — двоичная упаковка + base64url без JSON: `seed` (uint32), профессия (индекс), `week`, `freedomWeek`
  (0 — нет), путь — % свободы **через неделю** (недели 1, 3, 5…; призрак между ними — линейно), каждое значение — байт
  (% / 4, потолок 255), моменты — не больше 8 важнейших (свобода, первые покупки и улучшения по времени) по 4 байта,
  имя и остров — UTF-8 с длиной (имя до 24 байт, остров до 32). Цель: для 40 недель и 8 моментов — не больше ~150 символов кода.
- Старые ссылки `v: 1` по-прежнему открываются. Кривой код — `null`, без падений.

## 2. Окно «Поделиться»: имя, пол, ссылка-слово

- Поле «Имя на карточке» (`nameLabel`, плейсхолдер `namePlaceholder`): подставлено имя игрока, но если это имя по умолчанию
  (`meta.defaultPlayer` — «Вы»/«You»), поле пустое. Переключатель «он / она» (`he` / `she`; только для RU), не выбран —
  нейтральные тексты. Имя и пол запоминаются (`localStorage`, в `try/catch`) и сразу перерисовывают превью (с задержкой ~300 мс).
- Имя в ссылке-вызове — из поля; пустое — `friendName` («Друг»).
- «Скопировать сообщение» (`copyMessage`, вместо «Скопировать ссылку»): `ClipboardItem` с `text/html` (текст + `<a href>` со словами
  `linkWord`) и `text/plain` (текст + ссылка) → тост `messageCopiedLink`; без HTML-буфера — только текст → `messageCopied`.
- Поле с текстом показывает простой вариант (текст + короткая ссылка). Telegram/ВКонтакте/WhatsApp — как сейчас (ссылка уже короткая).

## 3. Карточка (1080×1350) и сообщение

Сверху вниз: снимок острова; **имя** (крупно, акцентным цветом); глагол (`verb[пол]`) и **`weeks(…)`** — самым крупным;
пояснение (`cardExplain`, уже есть); `cardMeta` (профессия · остров, уже есть); в партии-вызове — сравнение (уже есть);
**`callTitle`** и `callText`; внизу `footer` и адрес. Без имени — сразу `verb.neutral`. Длинные имя/остров — перенос или
многоточие, ничего не обрезается.

| Ключ `ui.challenge.*` | RU |
|---|---|
| `verb.male` / `verb.female` / `verb.neutral` | `'обрёл финансовую свободу'` / `'обрела финансовую свободу'` / `'Финансовая свобода'` |
| `weeks(weeks)` | `` `за ${weeks}!` `` |
| `callTitle` | `'Сможешь быстрее?'` |
| `callText` | `'Сыграй на этом же острове — бесплатно, в браузере, 10 минут.'` |
| `footer` | `'Архипелаг — уютная игра про деньги и свободу'` |
| `message.male(weeks)` | `` `Я обрёл финансовую свободу за ${weeks} в «Архипелаге» — уютной игре про деньги. Сможешь быстрее?` `` |
| `message.female(weeks)` | `` `Я обрела финансовую свободу за ${weeks} в «Архипелаге» — уютной игре про деньги. Сможешь быстрее?` `` |
| `message.neutral(weeks)` | `` `Финансовая свобода за ${weeks} в «Архипелаге» — уютной игре про деньги. Сможешь быстрее?` `` |
| `linkWord` | `'Сыграй на моём острове →'` |
| `nameLabel` / `namePlaceholder` | `'Имя на карточке'` / `'Например, Дима'` |
| `he` / `she` | `'он'` / `'она'` |
| `friendName` | `'Друг'` |
| `copyMessage` | `'Скопировать сообщение'` |
| `messageCopiedLink` | `'Сообщение скопировано — ссылка спрятана в словах «Сыграй на моём острове»'` |
| `messageCopied` | `'Сообщение со ссылкой скопировано'` |

Простой текст сообщения: `message[пол](…)`, в партии-вызове + сравнение, затем `linkWord` и ссылка с новой строки.
Ключи, ставшие ненужными (`cardHeadline`, `cardCall`, старый `message`, `copyLink`, `linkCopied`), удалить из обоих словарей.
В EN пола нет: переключатель скрыт, `verb.*` — одинаковые.
