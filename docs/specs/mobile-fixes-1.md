# Правки по первой игре владельца на телефоне

Ветка `claude/mobile-fixes`. Всё — только раскладка для телефона (`max-width: 1023px`); компьютер не меняется.
Движок (`packages/engine`) и числа правил не трогать.

## Диагноз (воспроизведено координатором, Edge 390×844, касания)

1. **Карточка соседа уезжает вправо.** Касание аватара соседа в верхней панели открывает карточку из
   `.neighbor-dropdown` (`ui/Neighbors.tsx:327`): left 195 px, ширина 358 px, правый край 553 px при ширине экрана 390.
2. **Обучение «застревает» на шаге 2.** После «Следующая неделя» открывается окно итогов недели, а пузырь «Шаг 2 из 3 —
   завершите неделю» остаётся поверх окна (`.coach` z-index 70 выше `.modal-backdrop` 50). Шаг 3 появляется после
   закрытия окна — игроку кажется, что неделю надо завершить дважды.
3. **Вкладка «Отчёт» длинная.** `ui/Panels.tsx:28`: Freedom (99 px) → Dream (188) → Goals (**411**) → Statement (351).
   До отчёта недели — 750 px прокрутки.
4. **Шторка снизу** открывается и закрывается только кнопкой `.sheet-handle` (`ui/Panels.tsx:96`). Свайпа нет.
5. **Нет звука на телефоне.** `audio/useUiSound.ts` разблокирует звук только на `pointerdown` и `keydown`. На сенсорном
   экране `pointerdown` не даёт браузеру «действие пользователя» (оно — на `pointerup`/`touchend`/`click`), поэтому
   `AudioContext` остаётся `suspended`. Кроме того, `engine.ts → resume()` выходит, пока висит прежний `this.resuming`,
   так что повторные попытки не делаются.

## Задача — Codex

1. **Карточка соседа на телефоне** целиком в экране: по центру, слева и справа ≥ 12 px, по высоте не выходит за экран
   (прокрутка внутри). Закрывается касанием вне карточки, как сейчас.
2. **Обучение:** пока открыто любое окно (итоги недели, развилка, окно соседа, «Поделиться», отзыв), пузырь и рамка
   обучения не показываются. Шаг 3 появляется сразу после закрытия окна итогов (как сейчас).
3. **Цели во вкладке «Отчёт» (только телефон):**
   - Порядок: Freedom → **Цели (свёрнуты)** → Statement → Dream. После свободы (`freedomWeek !== null`) Dream
     поднимается сразу под Freedom: Freedom → Dream → Цели → Statement.
   - Свёрнутые цели — одна строка-кнопка высотой ≤ 56 px: «Цели», «✓ N из 11» (выполненные) и маленькие значки
     целей в работе (те, что сейчас на виду, до 3): кольцо 16–18 px, заполненное по прогрессу цели, если он есть,
     иначе пустой кружок; `title` / `aria-label` — название цели. Справа шеврон ▾/▴. `aria-expanded`.
   - Касание раскрывает нынешний список целей без изменений; повторное — сворачивает. Состояние — в
     `localStorage` `archipelago.goals.open.v1` (в try/catch), по умолчанию свёрнуто.
   - Если на этой неделе цель выполнена, на свёрнутой строке — маленькая метка «+1» (до раскрытия).
   - Вкладка «Цели» на компьютере не меняется.
4. **Свайп шторки:** вертикальный свайп по верхней зоне шторки (ручка, мини-прогресс, ряд вкладок) — вверх открывает,
   вниз закрывает; порог 40 px или быстрый жест. Во время свайпа шторка следует за пальцем, после — доводится до
   открытого/закрытого положения прежней анимацией. Касание ручки по-прежнему переключает. Прокрутка внутри
   вкладки не меняется (свайп не ловится в `.tab-scroll`). Pointer events + `touch-action: none` на зоне.
5. **Звук на телефоне:** разблокировать на `pointerdown`, `pointerup`, `touchend`, `click`, `keydown` (capture,
   `isTrusted`). В `resume()` при вызове из жеста заново вызывать `context.resume()`, даже если прежний промис ещё
   не завершён. Записанные звуки (`HTMLMediaElement`) после разблокировки должны доиграть, как сейчас.
6. **Словари RU/EN** (`i18n/ru.ts`, `en.ts`): `ui.goals.show` «Показать цели» / “Show goals”, `ui.goals.hide`
   «Скрыть цели» / “Hide goals”, `ui.goals.newDone(n)` «+{n}» / “+{n}”. Имеющиеся строки «Цели», «Выполнено N из M»
   переиспользовать.

## Проверка

Исполнитель: `npm run -s typecheck`, `npm test` (238), `npm run -s build` — без ошибок. Браузер не запускать.
Координатор: Playwright, Edge 390×844 с касаниями — карточка соседа в экране, пузырь обучения скрыт при окне итогов,
высота свёрнутых целей и позиция отчёта, свайп шторки (CDP touch), `AudioContext.state === 'running'` после касания
при `--autoplay-policy=user-gesture-required`; компьютер 1366×768 без изменений.
