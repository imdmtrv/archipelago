# Залипательность, шаг 1: развилки, цели, слухи

Ветка `claude/engagement-1`. Владелец заметил, что события однообразны и не трогают эмоции: болезнь, подарок и шторм
просто случаются с игроком. Эмоции дают собственные решения и близкие цели. Делаем три вещи из этапа 5
[дорожной карты](../ROADMAP.md), без новых 3D-моделей и в духе [принципов](../ROADMAP.md#принципы): каждое — урок о деньгах,
решения важнее удачи, без штрафов «потеряй всё», без таймеров и давления, баланс — через симулятор.

1. **Развилки** — события с выбором: сосед просит в долг; повышение с переездом; покупатель на ваш актив.
2. **Цели** — три цели на виду, без сроков; за выполненную — небольшая награда и следующая цель.
3. **Слухи** — общие события (шторм, косяк рыбы, наплыв туристов, кризис) планируются за 2–4 недели, и о них идёт слух.
   Чтобы слух о шторме не превращал страховку в лазейку, страховка начинает действовать через 4 недели после оформления.

Каждый исполнитель читает «Общие правила», «Контракт» и свой раздел.

- Не ставь пакеты, не меняй `package.json`/`package-lock.json`, глобальные настройки, git (никаких commit / checkout / reset / stash).
- Проверка из корня: `npm run -s typecheck`; движок — ещё `npm test -- --reporter=dot` и `npm run -s sim`
  (все строки целей — `OK`). Не подгоняй цели симулятора под результат: меняй правила (числа в `rules.ts`, награды)
  в разумных пределах, а если цель всё равно не держится — сообщи числа.

## 1. Движок — исполнитель Codex 1

**Файлы:** `packages/engine/**` (src, test, scripts). Новые модули — по смыслу (например, `goals.ts`, `choices.ts`, `rumors.ts`).

### Слухи

- `settleWeek`: вместо броска события «на эту неделю» — (1) срабатывают события из `world.upcoming` с `week === endedWeek`
  (применяются как сейчас: шторм, косяк, бум, кризис; удаляются из списка); (2) с шансом `WORLD_EVENT_CHANCE` планируется
  новое: вид по `WORLD_EVENT_WEIGHTS`, срок `L = int(RUMOR_LEAD)`, `week = endedWeek + L`; если на эту неделю уже что-то
  запланировано — ничего не планируем. `windowStart = week − int(0, 1)`. Не больше одного события на неделю.
- В неделю планирования каждому игроку в отчёт — событие `rumor` (см. таблицу).
- `rumorViews(world, playerId)`: запланированные события как `{ kind, fromWeek: windowStart, toWeek: windowStart + 1,
  exactWeek: knowledge ≥ RUMOR_EXACT_KNOWLEDGE ? week : null }`, по возрастанию недели.

### Страховка заранее

- `setInsurance on`: `insured = true`, `insuranceFrom = world.week + INSURANCE_WAIT_WEEKS` (если уже застрахован — не менять);
  `off`: `insured = false`, `insuranceFrom = null`. Премия списывается с момента оформления.
- Болезнь и шторм покрываются, только если `insuranceActive(player, endedWeek)`.
- В неделю `endedWeek === insuranceFrom` — событие `insuranceStarted`.
- Слух о шторме идёт за 2–4 недели, страховка оформляется за 4: застраховаться, услышав о шторме, уже не успеть.

### Развилки (только у человека; боты их не получают)

- В конце `settleWeek` (после всех проверок): если у игрока-человека нет развилки, `endedWeek ≥ 3`
  и `endedWeek − lastChoiceWeek ≥ CHOICE_COOLDOWN`, то с шансом `CHOICE_CHANCE` выпадает развилка: вид по `CHOICE_WEIGHTS`
  среди доступных (веса недоступных отбрасываются; нет доступных — нет развилки). `PendingChoice.week = endedWeek + 1`,
  `lastChoiceWeek = endedWeek`, uid — `nextUid(world, 'c')`.
- Нерешённая к концу своей недели развилка снимается молча (считается отказом) — в начале `settleWeek`.
- **Сосед просит в долг** (`neighborLoan`). Сосед: бот с займом у ростовщика, иначе бот с наименьшими наличными.
  Сумма — `NEIGHBOR_LOAN_ASK`, округление до 10. Доступна, если у игрока наличных ≥ суммы + 50.
  Принять: игрок −сумма, сосед +сумма, `lent` += `{ dueWeek: world.week + int(NEIGHBOR_LOAN_DUE), tries: 0 }`,
  счастье +`NEIGHBOR_LOAN_JOY`. Возврат — в `settleWeek` после начислений, до ростовщика: в неделю `dueWeek` сосед
  отдаёт `round(сумма × (1 + NEIGHBOR_LOAN_BONUS))`, если у него наличных ≥ этого + 100 → `neighborLoanReturned`;
  иначе `tries + 1` и `dueWeek + NEIGHBOR_LOAN_RETRY` → `neighborLoanLate`; после `NEIGHBOR_LOAN_TRIES` неудач →
  `neighborLoanLost`, запись удаляется. Исход решает настоящее положение соседа — урок: смотри, кому одалживаешь.
- **Повышение с переездом** (`promotion`). Доступно на работе и при `promotions < PROMOTION_MAX`. Принять: зарплата
  +`PROMOTION_SALARY`, расходы +`PROMOTION_LIVING`, счастье +`PROMOTION_JOY`, `promotions + 1`. Урок: +5 в неделю,
  а финиш свободы отодвинулся на 35.
- **Покупатель на актив** (`buyer`). Доступна, если есть неповреждённый доходный актив (`kind: 'asset'`, не слот `finance`).
  Актив выбирается случайно среди таких; `offer = round10(price × range(BUYER_PREMIUM))`, где `price` — уплаченная цена
  с улучшениями. Принять: актив уходит, игрок +offer. Урок: капитал сразу или поток каждую неделю.
- `resolveChoice`: нет развилки → `noChoice`. Отказ — просто снять. Согласие — как выше; не хватает монет → `notEnoughCash`;
  актив уже продан или сломан → `noSuchAsset` и развилка снимается.
- `choiceView` — по типу `ChoiceView`: у займа `returnAmount`, `canAccept` и `reason`; у повышения и покупателя —
  доля свободы до и после (как `FinanceView.freedomRatio`), у покупателя ещё `saleValue` и `weeklyIncome`.

### Цели (только у человека)

- `createWorld`: `goals.active` — первые `GOALS_ACTIVE` доступных из `GOALS`.
- В конце `settleWeek`, до развилок: обновить счётчики (`calmWeeks` — 0 в неделю займа у ростовщика, иначе +1; `hadLoan` —
  был ли обычный кредит; `insuredStorm` — сработал шторм, а у игрока действующая страховка и есть имущество с риском шторма).
  Затем каждая активная цель с `value ≥ target` выполняется: в `done`, награда (монеты и счастье), событие `goalDone`.
  Освободившиеся места — следующими по порядку `GOALS`, ещё не выполненными и доступными (`debtFree` — только если `hadLoan`).
- Прогресс (`value` / `target`): `study` — знания (до 1) / 1; `cushion` — наличные / 3 × все расходы в неделю;
  `sectors` — число секторов доходных активов (без афер) / 3; `passive100` — настоящий пассивный доход (без афер) / 100;
  `upgrade` — есть ли актив 2-го уровня и выше / 1; `noLoanShark` — `calmWeeks` / 15; `share30` — % пассивного дохода
  от всех доходов / 30; `halfway` — % свободы / 50; `insuredStorm` — 0 или 1 / 1; `debtFree` — кредит был и сейчас кредитов
  нет / 1; `level150` — % свободы / 150. Проценты — целые.
- `goalsView` — активные цели с прогрессом и наградой, выполненные, `total = GOALS.length`.

### Миграция, симулятор, тесты

- `migrateWorld`: версии 1–4 → 5. Новые поля: `insuranceFrom = insured ? week : null` (старая страховка действует сразу),
  `choice: null`, `lastChoiceWeek: 0`, `promotions: 0`, `lent: []`, `goals` — начальный набор у человека, `null` у ботов,
  `upcoming: []`.
- `scripts/policies.ts`: разумный игрок решает развилки — одалживает, только если у соседа нет займа у ростовщика,
  его недельный итог (`financeView(...).net`) положительный и у самого остаётся ≥ 150; от повышения с переездом
  отказывается; покупателю продаёт, если `offer ≥ 25 × weeklyIncome`.
- Новые стратегии и цели в `simulate.ts` (новые строки целей, существующие не трогать):
  - «Переезжает всегда» (разумный, но всегда принимает повышение): медиана недели свободы не раньше, чем у разумного.
  - «Одалживает всем» (разумный, но соглашается на любой заём): медиана свободы позже разумного не больше чем на 6 недель
    (не катастрофа), а доля возвращённого у разумного больше, чем у щедрого (смотреть, кому одалживаешь, — выгодно).
  - «Слушает слухи» (разумный + при слухе о кризисе не покупает туристическое, при слухе о косяке/буме предпочитает
    сделки этого сектора): медиана свободы не позже разумного и раньше не больше чем на 3 недели (слухи помогают, но не решают).
  - Цели достижимы: у разумного к 100-й неделе выполнено ≥ 6 целей (медиана).
- Тесты (vitest): слухи (событие случается в названном окне; не больше одного на неделю; `exactWeek` по знаниям; детерминизм);
  страховка (шторм до `insuranceFrom` ломает, после — нет; `insuranceStarted`); развилки (доступность, принять/отказать, снятие
  нерешённой, возврат/отсрочка/потеря займа по наличным соседа, нет у ботов); цели (начальный набор, награда, порядок выдачи,
  `debtFree` только после кредита); миграция v4 → v5. Старые тесты — зелёные (меняй их, только если они проверяли старое
  поведение страховки или броска событий, и напиши об этом).

- **Окно развилки** (`ui/ChoiceModal.tsx`). Открывается, когда у человека есть развилка: после закрытия окна недели
  (или после тоста недели, если окна не было) и при нажатии «Следующая неделя», пока развилка не решена (неделя тогда
  не заканчивается, тост `t.ui.choices.pending`). Наверху `kicker`, заголовок, текст; цифры последствий: у займа — сумма
  и «вернёт …», ссылка «посмотреть карточку соседа» (открывает карточку соседа; окно развилки вернётся по «Следующей неделе»),
  подсказка; у повышения — «Свобода: X% → Y%» и чистая прибавка; у покупателя — предложение против обычной продажи,
  доход в неделю, «Свобода: X% → Y%». Две кнопки: согласиться (основная) и отказаться; `canAccept: false` — кнопка неактивна
  с текстом ошибки. Результат — тост (`lent`, `done`, `sold`, `declined`). Окно закрывается кнопками и Escape (Escape — без решения).
- **Цели** (`ui/GoalsBlock.tsx`). Заголовок, «Выполнено n из N», три активные цели: название, короткий текст, полоска
  `value / target`, награда (монеты, «+n к счастью»). Все выполнены — `allDone`. Место: рядом с блоком мечты — на компьютере
  в левой колонке под мечтой, на телефоне во вкладке «Отчёт» под мечтой. Выполненная цель приходит событием `goalDone`
  в окне недели.
- **Слухи.** На вкладке «Сделки» рядом с плашками рынка («Рыба в цене», «Туристы как обычно») — плашки слухов из
  `rumorViews`: `t.ui.rumors.chip(вид, когда)`; шторм и кризис — «плохой» тон, косяк и бум — «хороший». С точной неделей —
  подсказка `exactHint`. Слово «когда» — общий помощник в `i18n/index.ts`: точная неделя → `exact(week)` или `thisWeek`;
  иначе если окно уже началось → `thisOrNext`, иначе `range(from − текущая, to − текущая)`.
- **События в окне недели** — `eventCopy` для новых id (таблица в «Контракте»); имя соседа и его род — как в `newsText`.
  Для `rumor` текущая неделя — та, что сейчас играется (после отчёта).
- **Страховка** во вкладке «Действия»: под переключателем — `insuranceWait(«4 недели»)`; если оформлена, но ещё не действует, —
  `insurancePending(insuranceFrom)`.
- **Режиссёрский режим** (`/?director`, ролики) не должен падать: его миры из `fixtures.json` — версии 4; пропусти их через
  `migrateWorld` при загрузке или сделай новый UI терпимым к отсутствию полей.
- Проверка: `npm run -s typecheck` и `npm run -s build 2>&1 | tail -5`.
