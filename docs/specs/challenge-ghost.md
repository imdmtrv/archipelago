# Вызов другу: картинка с результатом, ссылка на тот же остров, призрак в соседях

Ветка `claude/challenge-ghost`. Задумка владельца: «Поделиться» должно цеплять друзей игрока. Сейчас это текст со ссылкой.
Делаем вызов, как с призраком в гонках: Дима делится картинкой со своим островом и результатом; Аня открывает ссылку,
играет на том же острове (тот же `seed`), и Дима едет рядом «призраком» — записью своего пути к свободе.

Движок (`packages/engine`) не меняется: призрак — только интерфейс, в мир Ани он не вмешивается.
Общие правила — как в [engagement-1](engagement-1.md#общие-правила).

## Файлы

`apps/web/src/**` (новые модули — например, `challenge.ts`, `shareCard.ts`, `ui/GhostCard.tsx`), кроме `director/**`.
В `en.ts` новые строки — `'TODO'` (переведёт другой исполнитель); RU — нормальный текст.

## 1. Запись пути (всегда, у каждой партии)

- В `store` и в сохранение — `moments: { week; kind; defId?; level? }[]` (не больше 20): первая покупка каждого вида актива
  и каждое улучшение (в `act` при успехе), свобода, уровни свободы, этапы и готовность мечты (по отчёту недели).
  Путь свободы уже есть — `history[HUMAN]`. Старые сохранения без `moments` → `[]`.

## 2. Ссылка-вызов

- `challenge.ts`: `encodeChallenge(data)` / `decodeChallenge(code) → ChallengeData | null` — base64url от JSON с `v: 1`,
  строгая проверка формы и длины (кривой код → `null`, без падений). `ChallengeData`: `seed`, `name`, `island`,
  `week` (сколько недель сыграно), `freedomWeek | null`, `progress` (целый % свободы по неделям 1..week),
  `moments`. Ссылка: адрес сайта (с `en/` для английского) + `?c=<код>`.
- Открытие ссылки с `c`: событие аналитики `challenge-open`; параметр убрать из адреса (`history.replaceState`).
  Нет сохранённой партии — окно приветствия в режиме вызова: результат автора и предложение сыграть на том же острове
  (название острова предзаполнено), «Начать» создаёт мир с `seed` вызова (`newGame` получает необязательный `seed`).
  Есть сохранённая партия — тот же экран с выбором «Принять вызов» (партия будет заменена) / «Продолжить свою игру».
  Принятие — событие `challenge-start`.
- Текст о результате автора — без родовых окончаний (пол автора неизвестен): «Результат Димы: свобода за 37 недель на
  острове „Тихая Гавань“. Сыграйте на том же острове — сможете быстрее?»; если автор ещё не дошёл до свободы —
  «…за 20 недель — 45% пути к свободе. Догоните?».

## 3. Призрак

- `store.challenge: ChallengeData | null` — сохраняется с партией; обычная новая игра — `null`.
- Полоска соседей: чип призрака после соседей — полупрозрачный аватар с первой буквой имени, кольцо = его % на текущей
  неделе (`progress[week − 1]`, после конца записи — последнее значение), пометка «вызов». Призрака нет в рейтинге
  движка. Учесть измерение ширины полоски в `TopBar`. **Телефон:** верхняя строка заполнена до предела — там чип
  призрака заменяет ваш собственный аватар (ваш прогресс и так на шкале свободы); строка не должна стать шире.
- Нажатие на призрака — карточка (по образцу карточки соседа, проще): имя и «вызов», его % на этой неделе против вашего,
  график обоих путей, его моменты до текущей недели.
- Новости недели: моменты призрака этой недели — в ленте новостей («Дима (вызов): коптильня куплена», «…: свобода!»),
  без родовых окончаний.
- Окно свободы в партии-вызове: сравнение «Вы — 34 недели, Дима — 37: быстрее на 3 недели!» / «…медленнее на 2» /
  «у Димы в записи свободы ещё нет».

## 4. Картинка и «Поделиться»

- `shareCard.ts`: PNG 1080×1350 на canvas — снимок острова (кадр WebGL-сцены; если захват не удался — фон-градиент
  в палитре игры), «Архипелаг» шрифтом Unbounded, крупно результат («Свобода за 37 недель» или «45% к свободе за 20 недель»),
  название острова, в партии-вызове — «На 3 недели быстрее, чем Дима», призыв «Сможете быстрее?», адрес сайта.
  Тёплая диорама, как в игре; текст читается на телефоне.
- `share.ts`: ссылка-вызов + картинка. `navigator.canShare({ files })` → `navigator.share({ files, text, url })`;
  иначе — скачать PNG и скопировать текст со ссылкой (тост). Отмена пользователем — молча.
- Кнопки: окно свободы и эпилог (уже есть) + «Бросить вызов другу» в блоке свободы (левая колонка / вкладка «Отчёт»)
  — только после свободы (решение владельца: вызов «45% за 6 недель» непонятен).
- Аналитика: `challenge-open`, `challenge-start` — в тип событий `analytics.ts`; `share` — как раньше.
