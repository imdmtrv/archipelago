# Этап 3. Английская версия

Исполнитель: агент-разработчик (Codex). Проверяющий: Claude. Один PR из ветки `codex/launch-3-english`,
от `main` с влитыми этапами 1 и 2. Общие правила и решения владельца — в [launch.md](launch.md).

Цель: вся игра по-английски на том же качестве, что по-русски. Русская версия не меняется ни на букву.
Состояние игры не зависит от языка. Это нужно и сейчас (переключение языка посреди партии), и потом:
в мультиплеере у соседей могут быть разные языки.

## Как сейчас и что меняется

Русский текст сейчас живёт в двух местах:

- **интерфейс** (`apps/web/src`): строки прямо в компонентах, `store.ts` (тосты, всплывающие суммы),
  `format.ts` (`fmt` через `ru-RU`, склонения, названия секторов);
- **движок** (`packages/engine/src`) сам пишет готовые русские фразы и кладёт их в состояние:
  заголовки и тексты событий (`events.ts`), новости (`news.ts`), ошибки действий (`text.ts`),
  названия и описания сделок, улучшений и мечты (`content.ts`), предупреждение об афере и причины
  в `dreamView` (`selectors.ts`). Новости и события сохраняются в `localStorage` уже текстом.

Решение: **движок отдаёт данные, слова собирает интерфейс.** Движок перестаёт производить пользовательский
текст. Интерфейс берёт фразы из словарей `ru` и `en`.

## 1. Движок: данные вместо фраз

Правило: всё, что сейчас подставляется в текст, кладётся в событие, новость или ошибку как данные
(числа, id сделок, уровни, id игроков), а не как готовые слова.

- **События** (`GameEvent`): убрать `title` и `text`; добавить `params?: Record<string, number | string | string[]>`
  и `variant?: number`. `id`, `tone`, `cashDelta`, `affectedAssetUids` остаются как есть.
- **Варианты фраз и детерминизм.** Сейчас `pickText(rng, variants)` выбирает вариант текста генератором случайных
  чисел. Заменить на `pickVariant(rng, count)` с **тем же самым вызовом** `rng.int(0, count - 1)` в том же месте
  и с тем же `count`, что сейчас (число вариантов в русском тексте). Номер варианта — в `event.variant`.
  Число вариантов каждого события — константы движка `EVENT_VARIANTS` (например, `breakdown: 3`).
  В словарях `ru` и `en` вариантов ровно столько же. Порядок русских вариантов сохранить: вариант `i` в `ru` —
  прежний текст `i`.
- **Новости** (`WeekReport['news']`): `{ playerId, kind, ...данные }` вместо `{ playerId, text }`.
  `kind` — по функции в `news.ts` (`bought`, `sold`, `upgraded`, `loan`, `repaid`…), данные — что эти функции
  подставляли (`defId`, `level`, `amount`…). Род глагола («купил/купила») решает русский словарь по `playerId`:
  `FEMALE_BOT_IDS` переезжает туда.
- **Ошибки действий**: `applyAction` возвращает `error?: EngineError` вместо строки:

  ```ts
  export type EngineError =
    | { code: keyof typeof ERROR_CODES }                 // нынешние ERRORS без параметров
    | { code: 'notEnoughCash'; missing: number }
    | { code: 'needKnowledge'; level: number }
    | { code: 'loanOverLimit'; limit: number }
    | { code: 'slotFull'; slot: SlotType };
  ```

  Все места, где ошибка используется (`store.ts`, `gameSounds.ts`, `bots.ts`, `scripts/simulate.ts`), — по смыслу:
  в UI текст из словаря, в логах ботов и симуляторе — `code`.
- **Контент**: из `ASSET_DEFS`, `upgrades`, `DREAMS` убрать `title` и `description`. `DEAL_ACCUSATIVE`, `UPGRADE_NAMES`,
  `FREEDOM_LEVEL_TITLES`, `SLOT_FULL_TEXT`, `ERRORS`, `SCAM_WARNING`, склонения из `text.ts` переезжают в словари интерфейса.
  `AssetView.title` и `OfferView.warning` — заменить данными: `level` уже есть, `warning?: 'scam'`.
  `dreamView().reason` — код: `'beforeFreedom' | 'done' | 'building'`.
- **Имена соседей**: `BOT_ROSTER` в `world.ts` не трогать. Эти имена видят старые сохранения и тесты,
  но интерфейс их больше не показывает: имя и остров соседа берутся из словаря по `player.id`.
  Это единственные кириллические строки, которые остаются в коде движка (комментарии не в счёт).
- **Версия мира** растёт на 1, `migrateWorld` переводит старые сохранения: у старых событий в `lastReport`
  прежние `title` и `text` переезжают в `legacyTitle` и `legacyText`. Интерфейс показывает их как есть,
  если у события нет `params` и `variant`. Старые новости в сохранении (`news` в `store.ts`) — `{ week, text, playerId }`:
  показываются своим текстом. Новые — из словаря.
- **Баланс не меняется ни на монету.** Перед правками сохранить вывод `npm run sim` с `main`; после — вывод совпадает
  побайтно. Тесты движка: строки в проверках заменяются кодами (`expect(result.error).toEqual({ code: 'slotFull', slot: 'pier' })`);
  число тестов не уменьшается; числа в проверках не меняются.

## 2. Интерфейс: словари

- Новая папка `apps/web/src/i18n/`:
  - `ru.ts` — все пользовательские строки игры; прежние русские тексты переносятся **дословно**.
    Значения — строки или функции (склонения, род, подстановки чисел), например
    `bought: (p: NewsPlayer, defId: string) => …`;
  - `en.ts` — тот же набор ключей: `const en: Dict = …`, где `type Dict = typeof ru`. Пропущенный ключ —
    ошибка компиляции;
  - `index.ts` — текущий язык (маленький zustand-стор), хук `useI18n()` → `{ t, lang, fmt, signed, plural }`
    для компонентов и `getI18n()` для кода вне React (`store.ts`, `share.ts`, `analytics.ts`, `coach.ts`).
- Числа: `fmt` через `Intl.NumberFormat` (`ru-RU` → «1 240», `en-US` → «1,240»). Минус — по-прежнему типографский «−».
  Множественное число — через `Intl.PluralRules` (в `ru` формы one/few/many, в `en` — one/other).
- Переводятся все экраны игры: приветствие, шапка, соседи и их карточки, лента новостей, вкладки, карточки сделок,
  остров, действия, отчёт, мечта, окна недели и свободы, эпилог, тосты, всплывающие суммы над островом,
  подсказки обучения, «Поделиться», ссылка на отзыв, панель звука и заставка загрузки
  (в `en/index.html` — «Archipelago»).
- **Не переводятся** инструменты владельца: витрина `/?sound` (подписи звуков в `cues.ts`) и песочница `/?sandbox`.
- Имя игрока по умолчанию: если имя человека равно «Вы» или «You», показывать вариант текущего языка.
  Остальные имена и названия островов, введённые человеком, показываются как есть.

## 3. Выбор языка

- Порядок: путь `/en/` (с учётом базового пути) → английский всегда. Иначе — сохранённый выбор
  `localStorage archipelago.lang.v1` (`ru` | `en`). Иначе — русский (`ru`). Язык браузера больше
  не учитывается: русскоязычные игроки с английским телефоном попадали на английскую версию.
- **Переключатель** — две маленькие кнопки «RU» и «EN», текущая — золотая (как выбранный вариант в витрине звука):
  в окне приветствия в правом верхнем углу и в панели звука отдельной строкой «Язык» / «Language».
  Переключение мгновенное, без перезагрузки; выбор сохраняется; обновляются `document.documentElement.lang`
  и `document.title`; событие аналитики `lang-switch` (`title` — новый язык; добавить в union из этапа 2).
- **Вторая HTML-страница** `apps/web/en/index.html` для превью английских ссылок: соцсети не выполняют JS
  и читают мета-теги из HTML. Копия `index.html` с `lang="en"` и английскими мета-тегами:
  - `<title>` и `og:title`: «Archipelago — a cozy game about money and freedom»;
  - `description` и `og:description`: «Your own island, 600 coins and one goal — financial freedom. Buy assets,
    dodge scams and beat your neighbors. Free in your browser.»;
  - `og:locale` `en_US`, `og:url` `%VITE_SITE_URL%en/`, `og:image` `%VITE_SITE_URL%og-image-en.jpg`,
    `og:image:alt` «A cozy low-poly island with boats, cottages and a lighthouse»;
  - заставка — с «Archipelago».
  Добавить обе страницы во входы сборки Vite (multi-page). Адрес: `https://dmtrml.github.io/archipelago/en/`.
- `scripts/make-social-images.mjs` получает `--lang en`: тот же кадр, плашка «Archipelago» /
  «A cozy game about money and freedom» / «Play free in your browser» → `apps/web/public/og-image-en.jpg`.

## 4. Как переводить

Перевод — по смыслу, а не слово в слово: короткие, тёплые, понятные ребёнку фразы, обращение на «you».
Шутки и интонация событий сохраняются. Кнопки — с заглавной буквы только первое слово («Next week», «Buy for 250»).

**Глоссарий — обязателен, без синонимов:**

| Русский | English |
|---|---|
| Финансовая свобода | Financial freedom |
| До финансовой свободы | To financial freedom |
| Пассивный доход | Passive income |
| Доход / Расходы / Итого | Income / Expenses / Net |
| Наличные / Имущество / Долги / Капитал | Cash / Property / Debt / Net worth |
| Счастье / Знания | Happiness / Knowledge |
| Сделки / Остров / Действия / Отчёт | Deals / Island / Actions / Report |
| Следующая неделя | Next week |
| Актив / Пассив / статус | Asset / Liability / status |
| Содержание (в неделю) | Upkeep |
| Окупится за N нед. | Pays back in N wk |
| /нед | /wk |
| монета, монеты | coin, coins |
| Афера | Scam |
| Заём у ростовщика | Loan shark |
| Кредит / погасить | Loan / repay |
| Страховка | Insurance |
| Подработка | Extra shift |
| Учиться / Отдохнуть | Study / Rest |
| Улучшить | Upgrade |
| Починить | Repair |
| Мечта | Dream |
| Шхуна для кругосветки | Round-the-world schooner |
| Стапель | Slipway |
| Свобода / Уверенность / Богатство (уровни) | Freedom / Confidence / Wealth |
| Свобода под угрозой | Freedom at risk |
| Соседи / Гонка к свободе | Neighbors / Race to freedom |
| Уйти с работы / Вернуться на работу | Quit your job / Go back to work |
| Эпилог | Epilogue |

Имена и места — как в решениях владельца: Mia, Timur, Boris; Seashell, Lighthouse, Pelican; Quiet Harbor; You.

**Длина.** Где места мало (вкладки, подписи показателей, кнопки, плашки), английская строка не длиннее русской
больше чем на 20% — иначе подобрать короче, не меняя смысла. Проверка — скриптом (ниже) и на скриншотах.

Носитель языка может вычитать перевод позже, отдельной задачей владельца. Эта спецификация такой вычитки не требует.

## Критерии приёмки (по ним проверяет Claude)

1. `npm run typecheck`, `npm test`, `npm run build` проходят. Вывод `npm run sim` побайтно совпадает с `main`
   (оба вывода — в документ приёмки, или их хеши и `diff`).
2. В строковых литералах `packages/engine/src` нет кириллицы, кроме `BOT_ROSTER`:
   `grep -nP "['\"\`][^'\"\`]*[А-Яа-яЁё]"` по строкам без комментариев — вывод в документ приёмки.
3. **Русский не изменился.** Скрипт `scripts/check-i18n.mjs` проходит один и тот же сценарий на `main` и на ветке
   (фиксированные миры через `createWorld` / `applyAction` в `archipelago.save.v1`, как в прошлых проверках):
   приветствие, все вкладки, покупка, улучшение, кредит, неделя с событиями (шторм, афера, повышение),
   окно свободы, угроза свободе, эпилог, карточка соседа, панель звука. На каждом экране снимает
   `document.body.innerText`. На ветке в режиме RU тексты **совпадают** с `main`. Единственные допустимые
   различия — переключатель «RU / EN» и строка «Язык» (они перечислены в документе приёмки).
4. **Английский полный.** Тот же сценарий в режиме EN, 390×844 и 1366×768:
   - в `innerText` нет кириллицы (имя игрока — «You», остров — «Quiet Harbor»);
   - нет горизонтального переполнения: у элементов внутри `.hud`, `.modal`, `.sheet` с текстом
     `scrollWidth <= clientWidth + 1`; исключение — элементы с `text-overflow: ellipsis`;
   - скриншоты 6–8 ключевых экранов EN — в документ приёмки.
5. Выбор языка: `/en/` → EN; корень без сохранённого выбора всегда открывается на RU независимо от языка браузера
   (`de-DE` → RU); сохранённый выбор имеет приоритет; переключатель меняет язык без перезагрузки посреди партии —
   и новости, и события, и тексты на острове.
6. Старое сохранение с `main` (версия мира 3, новости и события с русским текстом) загружается без ошибок;
   старые новости видны прежним текстом; новая неделя — на выбранном языке.
7. `dist/en/index.html` содержит английские мета-теги с полными адресами; `og-image-en.jpg` в документе приёмки.
8. Число вариантов каждого события в `ru` и `en` равно `EVENT_VARIANTS` — проверяется в `scripts/check-i18n.mjs`.
9. Документ приёмки `docs/qa/launch-3-english.md`, обновлены `STATUS.md` и `docs/status-history.md`.
