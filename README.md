# Архипелаг

English: [README.en.md](README.en.md)

**Играть:** https://imdmtrv.github.io/archipelago/

Мультиплеерная экономическая игра, которая учит управлять деньгами: у каждого игрока свой остров,
активы приносят пассивный доход, статусные вещи только тянут расходы, цель — финансовая свобода.

## Запуск

```bash
npm install
npm run dev        # игра: http://localhost:5173  (витрина 3D-сцены: /?sandbox)
npm test           # тесты движка
npm run sim        # симуляция баланса: тысячи партий ботами
npm run typecheck
```

Витрина звука: `http://localhost:5173/?sound`. Настройки — кнопка динамика рядом с «↺».
У каждого звука можно выбрать синтез или запись. В исходном наборе записи выбраны для отказа,
дождя, грома, музыки острова и свободы; остальные звуки синтезированы. Авторы и лицензии —
в [CREDITS.md](CREDITS.md). При ошибке записи используется резервный синтез. Для отладочного журнала задайте
`localStorage.setItem('archipelago.audio.debug', '1')` и перезагрузите страницу.

Публикация: каждый push в `main` собирает игру и выкладывает её на GitHub Pages через
`.github/workflows/deploy.yml`; проверки запускаются из `.github/workflows/ci.yml`.

## Устройство

```
packages/engine   — правила игры: чистый детерминированный TypeScript без UI и сети
                    (state, action) → state; вся случайность через seed — готово к мультиплееру
apps/web          — React + React Three Fiber
  src/scene       — 3D-остров (контракт с UI: scene/contract.ts)
  src/ui          — интерфейс: отчёт, сделки, действия, соседи
  src/store.ts    — состояние игры, сохранение в браузере
concept/          — исходный визуальный концепт (эталон стиля)
docs/             — спецификация MVP и арт-дирекшн
```
